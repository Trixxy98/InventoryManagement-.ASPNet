# 05 — UI Design

## 1. Routes

| Path | Page | Tujuan |
|------|------|--------|
| `/` | Dashboard | 4 kad + senarai low/out of stock |
| `/products` | Products | Table, search, filter, add/edit/delete |
| `/categories` | Categories | CRUD kategori |
| `/stock` | Stock | Form in/out + history table |

│  Stock       │                                              │

     240px                         flex-1

- Sidebar tetap, active link highlight (indigo)
- Background page: gray-50, card putih, shadow kecil
- Font: system / Inter (Tailwind default OK)

**Warna kad (cadangan)**

| Kad | Icon / accent |
|-----|----------------|
| Total Products | slate |
| Total Stock | indigo |
| Low Stock | amber — klik bawa ke `/products?stockStatus=low` (optional) |
| Out of Stock | rose |

Format nombor: `toLocaleString()` → `3,450`.

## 4. Products wireframe

```
Products                              [ + Add Product ]
────────────────────────────────────────────────────────
Search [__________]  Category [ All ▼ ]  Status [ All ▼ ]

Name             Category      Price    Qty   Min   Status        Actions

```

- Row Out of stock: background rose-50 (subtle)
- Row Low stock: amber-50
- Empty search: "No products found"

### Modal Add / Edit

```
┌─────────────────────────────────┐
│ Add Product                 [x] │
│ Name            [____________]  │
│ Category        [ Select    ▼]  │
│ Price           [____________]  │
│ Quantity        [____________]  │  ← hidden / disabled on Edit
│ Minimum stock   [____________]  │
│            [Cancel]  [Save]     │
└─────────────────────────────────┘
```

Edit: Quantity tidak muncul. Hint kecil: "Change quantity via Stock In / Stock Out."

Delete: `window.confirm` atau modal "Delete USB Cable? This cannot be undone."

## 7. Components (kecil, jangan 1 fail gergasi)

| Component | Guna |
|-----------|------|
| `Layout.jsx` | Sidebar + `<Outlet />` |
| `StatCard.jsx` | Dashboard kad |
| `StockBadge.jsx` | In / Low / Out pill |

Pages boleh contain table + modal sendiri (cukup untuk v1). Pecah modal nanti jika fail > ~250 baris.

## 8. Frontend state

- Tiada Redux
- Setiap page: `useState` + `useEffect` fetch
- Selepas mutation: fetch semula list (simple, jelas untuk belajar)

`src/api.js` — axios instance:

```
baseURL: http://localhost:5088/api
```

## 9. Empty & error

| Situasi | UI |
|---------|-----|
| API down | Banner merah: "Cannot reach API. Is backend running on :5088?" |
| Senarai kosong | "No products yet. Add your first product." |
| Validation | Teks merah bawah field ATAU alert dari `message` |
